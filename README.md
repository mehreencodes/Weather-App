# 🌤️ Weather Station — Premium Weather App

A modern, feature-rich weather app that gives you real-time conditions, hourly and 5-day forecasts, live air quality, and more for any city in the world. Built entirely with **HTML, CSS, and vanilla JavaScript** — no frameworks — and powered by the **OpenWeatherMap API**.

## 🔗 Live Demo

Check it out here: [Weather Station Live](https://weather-app-nine-ecru-11.vercel.app/)

## 📸 Features

- 🔍 **City search with live autocomplete** — suggestions appear as you type, with full keyboard navigation.
- 📍 **"Use my location"** — instantly loads weather for your current position via geolocation.
- 🌡️ **Current conditions** — temperature, feels-like, description, and a custom animated weather icon.
- ⏱️ **Next 24 hours** — hourly forecast strip with a live temperature trend chart.
- 📅 **5-day outlook** — daily low/high temperatures and conditions at a glance.
- 🌬️ **Detailed metrics** — humidity, wind speed & direction (live compass), pressure, visibility, and calculated dew point.
- 🫁 **Live Air Quality Index (AQI)** — 1–5 scale with a color-coded gauge.
- 🌅 **Sunrise/sunset gauge** — visual horizon bar showing where the current local time falls in the day.
- 🕓 **Recent cities** — quick-switch chips for previously searched locations.
- 🌗 **Day/Night theme toggle** and **°C/°F unit toggle**.
- 🎬 **Weather-reactive animations** — falling rain, drifting snow, and sun rays react to current conditions.
- 📱 **Fully responsive** — clean experience on both desktop and mobile.
- ⚠️ **Graceful error handling** for invalid or unrecognized city names.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (glassmorphism, custom properties, animations, responsive design)
- **JavaScript** (Vanilla JS, Fetch API, async/await)
- **OpenWeatherMap API** — Current Weather, 5-Day Forecast, Geocoding, and Air Pollution endpoints

## 💻 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/DeclutterQueen/Weather-App.git
   ```
2. Open the project folder:
   ```bash
   cd Weather-App
   ```
3. Open `index.html` directly in your browser — no build step or server required.

> **Note:** The app uses a free OpenWeatherMap API key. If you fork this project, you may want to swap in your own key from [openweathermap.org](https://openweathermap.org/api).
